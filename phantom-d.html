📜 사건 기록

💎

사건: 고가의 보석을 훔친 괴도 D의 이동 흔적이 각 구역에 하나씩 남아 있다.

  • 각 가로줄·세로줄에 괴도는 정확히 한 명
  • 각 색깔 구역에도 정확히 한 명
  • 괴도끼리는 대각선으로도 붙을 수 없다
  • 처음부터 X가 표시되지 않아요. 색 구역의 크기·모양과 행·열 규칙을 이용하세요.
  • 그 판의 괴도를 모두 정확히 지목하면 자동으로 사건 해결!
  • 오답 3회면 게임오버, 해당 탐정 화면에 괴도 D의 해당 판의 정답 위치 공개 (다른 참가자는 계속 수사)

색 구역과 괴도 위치는 매 판 무작위로 달라져요. 크기별로 균형 잡힌 메인 색 구역과 한 칸짜리 구역 정확히 1개, 나머지 중간 크기 구역이 배치되고, 일반소거·묶음소거만으로 해결 가능하도록 만들어져요. 괴도 이미지 4종도 번갈아 나타나요.

모바일: 탭은 X 표시·해제, 두 번 탭하면 괴도 지목, 손가락으로 드래그하면 여러 칸 X 표시·삭제
PC: 클릭은 X 표시·해제, 더블클릭은 괴도 지목, 드래그는 여러 칸 X 표시·삭제 · 우클릭도 X
괴도를 잘못 지목한 횟수만 오답으로 집계돼요. X 표시 실수는 패널티가 없어요.

멀티: 모든 참가자가 같은 사건을 각각 풀어요. 가장 먼저 해당 판의 괴도를 전부 검거하면 승리하고 전원 경기가 끝나요. 오답 3회로 탈락한 사람은 관전할 수 있어요.
